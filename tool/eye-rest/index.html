    • 이 탭은 열어 두세요. 탭을 닫거나 Chrome 을 끄면 울리지 않아요.
    • 탭 위에서 우클릭하고 고정을 눌러 두면 실수로 닫을 일이 줄어요.

    알림이 안 뜰 때
    • 주소창 왼쪽 자물쇠(사이트 정보) → 알림 → 허용, 그다음 새로고침.
    • Windows 설정 → 시스템 → 알림에서 알림과 Google Chrome이 켜져 있는지 확인.
    • 집중 지원(방해 금지)이 켜져 있으면 배너가 숨어요. 끄거나 Chrome 을 우선순위 앱에 넣어 주세요.
    • Chrome 설정 → 성능 → 메모리 절약에서 이 사이트를 항상 활성 상태로 유지에 넣으면 오래 둔 탭이 잠들지 않아요.
