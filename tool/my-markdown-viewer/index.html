파일과 텍스트는 서버에 업로드하지 않아요. Markdown 안의 HTML은 실행하지 않고, 외부 이미지는 자동으로 불러오지 않아요. 문서 표시용 라이브러리는 처음 사용할 때 인터넷에서 내려받아요.
