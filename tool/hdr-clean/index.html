HDR C2PA 정리

직접 찍은 HDR 사진이나 직접 그린 파일을 원하는 크기로 자르거나 조금 다듬으려고 편집 도구를 썼을 뿐인데
그것만으로도 C2PA 편집 라벨이 붙어서 파일 전체를 새로 생성한 것처럼 오해받을 수 있어요.

그래서 HDR gain map과 픽셀은 그대로 지키면서 C2PA 같은 편집 라벨만 떼는 도구를 만들었어요.

옵션

기본은 C2PA 출처 정보, Software 태그, XMP CreatorTool과 softwareAgent, C2PA 원격 링크만 지웁니다. 직접 쓴 문구일 수 있는 자유 텍스트는 이 옵션을 켰을 때만 건드립니다.

    지우는 것

    • C2PA Content Credentials(서명된 출처 manifest)
    • EXIF Software, PNG Software 텍스트 중 편집 도구 라벨
    • XMP CreatorTool, History softwareAgent 중 편집 도구 라벨
    • XMP dcterms:provenance(원격 C2PA 링크)

    그대로 두는 것

    • HDR gain map 이미지와 그 metadata(Ultra HDR hdrgm, ISO 21496-1, Apple HDR)
    • MPF index, ICC profile, PNG cICP, mDCv, cLLi
    • 사진 픽셀: 처리 전후를 decode해서 같은지 확인한 뒤에만 결과를 줍니다

    한계

    • 픽셀 속에 숨긴 watermark는 metadata가 아니라서 찾지도 지우지도 못합니다.
    • 라벨을 지운다고 직접 만든 파일이라는 증거가 되지는 않습니다. 원본은 따로 보관해 두세요.
    • C2PA를 지우면 원본 서명으로 출처를 증명할 수 없게 됩니다.
